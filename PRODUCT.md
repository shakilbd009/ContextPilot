# Product

## Register

product

## Users

Professionals who attend recurring meetings and need to walk in prepared. They're time-poor, context-switching between calls, and want relevant background surfaced without hunting through old emails or notes.

## Product Purpose

ContextPilot surfaces relevant context from previous conversations before each meeting, so users arrive prepared rather than embarrassed. The interface is a tool — it should disappear into the task.

## Brand Personality

Confident, precise, quiet. No marketing fluff. The UI says "I respect your time" through restraint, clear hierarchy, and predictable patterns. Think Linear or Stripe: dense where density serves the user, sparse where focus matters.

## Anti-references

SaaS landing page aesthetics: gradient heroes, badge clutter, "AI-powered" copy, animated illustrations. Should NOT feel like a marketing site with a dashboard bolted on. Not Notion's playful noise. Not Intercom's chat-forward urgency.

## Design Principles

1. **Earned familiarity.** Use patterns users already know from Linear, Figma, Raycast. Structure earns trust through consistency, not novelty.
2. **Quiet confidence.** The tool serves the task, it doesn't announce itself. Hierarchy through spacing and weight, not color saturation.
3. **State completeness.** Every interactive element has all required states. Loading skeletons over spinners in content areas. Empty states that teach.
4. **Respect the flow.** Users are mid-task. Transitions are 150–250ms. No page-load choreography. No decorative motion.
5. **Accessible by default.** WCAG 2.1 AA minimum. Focus visible, contrast sufficient, keyboard navigation complete.

## Accessibility & Inclusion

- WCAG 2.1 AA compliance required
- Respects `prefers-reduced-motion`
- Semantic HTML, proper ARIA labels on all interactive elements
- Focus indicators visible and high-contrast
